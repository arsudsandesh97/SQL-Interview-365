# SQL Scenario-Based Interview Question: Lapsed Returners Re-engagement Segment

## Business Scenario
You are a Data Analyst at "Trendify", a fast-growing e-commerce clothing brand. The marketing team is planning a targeted re-engagement campaign. They are particularly interested in identifying customers who have recently made a return, but have not placed a new order for a longer period. These "Lapsed Returners" represent a segment that might be disengaging and could be swayed back with a specific offer. Your task is to extract this customer list, focusing on those who returned an item within the last 60 days but have not made any new purchases in the last 90 days.

Assume:
```sql
CURRENT_DATE = '2023-10-26'
```

---

# Database Setup

## Create Customers Table
```sql
CREATE TABLE Customers (
    customer_id INT PRIMARY KEY,
    customer_name VARCHAR(255),
    email VARCHAR(255)
);
```

## Insert Customers Data
```sql
INSERT INTO Customers (customer_id, customer_name, email) VALUES
(101, 'Alice Smith', 'alice@example.com'),
(102, 'Bob Johnson', 'bob@example.com'),
(103, 'Charlie Brown', 'charlie@example.com'),
(104, 'Diana Prince', 'diana@example.com'),
(105, 'Eve Adams', 'eve@example.com'),
(106, 'Frank White', 'frank@example.com');
```

## Create Orders Table
```sql
CREATE TABLE Orders (
    order_id INT PRIMARY KEY,
    customer_id INT,
    order_date DATE,
    total_amount DECIMAL(10, 2),
    FOREIGN KEY (customer_id) REFERENCES Customers(customer_id)
);
```

## Insert Orders Data
```sql
INSERT INTO Orders (order_id, customer_id, order_date, total_amount) VALUES
(1, 101, '2023-10-20', 120.00), -- Recent order
(2, 102, '2023-07-01', 85.50),  -- Old order (outside 90 days)
(3, 103, '2023-08-01', 50.00),  -- Old order (outside 90 days)
(4, 104, '2023-09-20', 200.00), -- Recent order
(5, 101, '2023-06-15', 75.00),  -- Old order
(6, 105, '2023-05-10', 150.00), -- Very old order
(7, 103, '2023-10-05', 30.00);  -- Recent order (for customer 103)
```

## Create Returns Table
```sql
CREATE TABLE Returns (
    return_id INT PRIMARY KEY,
    customer_id INT,
    order_id INT,
    return_date DATE,
    return_amount DECIMAL(10, 2),
    FOREIGN KEY (customer_id) REFERENCES Customers(customer_id),
    FOREIGN KEY (order_id) REFERENCES Orders(order_id)
);
```

## Insert Returns Data
```sql
INSERT INTO Returns (return_id, customer_id, order_id, return_date, return_amount) VALUES
```

# Task
Identify all customers who meet the criteria of "Lapsed Returners":
1.  They have made at least one return within the last 60 days (inclusive of `CURRENT_DATE`).
2.  They have NOT placed any orders within the last 90 days (inclusive of `CURRENT_DATE`).
For these customers, list their `customer_id`, `customer_name`, and their `most_recent_return_date`. Order the results by `most_recent_return_date` in descending order.

---

| customer_id | customer_name | most_recent_return_date |
