# SQL Scenario-Based Interview Question: Identifying Problematic Products and High-Return Customers

## Business Scenario
An e-commerce company is experiencing higher than desired product return rates. As a Data Analyst, your task is to identify specific products that might have quality issues or misleading descriptions (indicated by abnormally high return rates), and also to identify individual customers whose return behavior is unusually frequent. The goal is to inform product development, quality control, and customer service teams to address these issues.

Assume:
```sql
CURRENT_DATE = '2023-10-26'
```

---

# Database Setup

## Create Products Table
```sql
CREATE TABLE products (
    product_id VARCHAR(50) PRIMARY KEY,
    product_name VARCHAR(255) NOT NULL,
    category VARCHAR(100)
);
```

# Task
Calculate the return rate (total quantity returned / total quantity sold) for each product and each customer. The analysis should consider all orders placed and items returned within the last 12 months from `CURRENT_DATE`.

Then, identify:
1.  **Problematic Products**: Products whose calculated return rate is both greater than 20% AND higher than the overall average product return rate across all products.
2.  **High-Return Customers**: Customers whose calculated return rate is both greater than 15% AND higher than the overall average customer return rate across all customers.

Return a single result set containing these "problematic" entities, with their type, ID, name, and calculated return rate (rounded to 2 decimal places).

---
