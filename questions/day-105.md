# SQL Scenario-Based Interview Question: Identifying High-Churn-Risk Subscription Customers

## Business Scenario
You are a Data Analyst at 'Boxify', an e-commerce company specializing in curated subscription boxes. Boxify is experiencing subscriber churn and wants to be proactive in retaining customers. Your task is to identify 'high-churn-risk' customers who might cancel their subscriptions in the near future. This information will be used by the customer success team for targeted outreach and intervention.

Assume:
```sql
CURRENT_DATE = '2024-07-15'
```

---

# Database Setup

## Create customers Table
```sql
CREATE TABLE customers (
    customer_id INT PRIMARY KEY,
    first_name VARCHAR(50),
    last_name VARCHAR(50),
    email VARCHAR(100),
    subscription_status VARCHAR(20) -- e.g., 'Active', 'Paused', 'Cancelled'
);
```

## Create subscriptions Table
```sql
CREATE TABLE subscriptions (
    subscription_id INT PRIMARY KEY,
    customer_id INT,
    plan_name VARCHAR(50),
    start_date DATE,
    end_date DATE, -- NULL if active
    current_status VARCHAR(20), -- e.g., 'Active', 'Paused', 'Skipped Next', 'Cancelled'
    last_shipment_date DATE,
    next_shipment_date DATE,
    FOREIGN KEY (customer_id) REFERENCES customers(customer_id)
);
```

# Task
Identify all unique `customer_id`, `first_name`, `last_name`, and `email` for customers who are currently `Active` or `Paused` and show at least one of the following high-churn-risk indicators:

1.  **Skipped Next Shipment:** The customer has at least one associated subscription with `current_status` = 'Skipped Next'.
2.  **Recently Paused:** The customer has at least one associated subscription with `current_status` = 'Paused', and its `next_shipment_date` (if it were active) is within the next 30 days from `CURRENT_DATE`.
3.  **Low Recent Average Order Value (AOV):** For a customer's subscription, their average `total_amount` for their last 3 *completed* orders is less than 75% of their overall average `total_amount` for *all completed* orders. This indicator only applies to customers who have at least 3 completed orders in total for that subscription. If a customer has multiple subscriptions, this check applies to each, and if any single subscription meets this criterion, the customer is flagged.

The output should also include a `churn_indicators` column listing all applicable reasons, comma-separated. The order of indicators in the `churn_indicators` string does not matter.
