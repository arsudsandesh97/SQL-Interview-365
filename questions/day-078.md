# SQL Scenario-Based Interview Question: Customer Reactivation Analysis

## Business Scenario
You are a Data Analyst at an e-commerce company specializing in home goods. The marketing team is launching initiatives to re-engage inactive customers and wants to understand the patterns and frequency of customer reactivations. A customer is considered "reactivated" if they make a purchase after a significant period of inactivity. Specifically, an order qualifies as a reactivation if the customer's *previous* order was more than 90 days ago. The team needs to identify these reactivation events to measure the success of their re-engagement campaigns.

Assume:
```sql
CURRENT_DATE = '2023-10-26'
```

---

# Database Setup

## Create Orders Table
```sql
CREATE TABLE Orders (
    order_id INT PRIMARY KEY,
    customer_id INT NOT NULL,
    order_date DATE NOT NULL,
    total_amount DECIMAL(10, 2) NOT NULL
);
```

# Task
Write a SQL query to identify all customer orders that qualify as a 'reactivation'.
For each reactivation order, return the `customer_id`, `order_id`, `order_date`, and the `days_of_inactivity` (calculated as the number of days between the current order date and the immediately preceding order date for that customer).
Exclude a customer's very first order, as it cannot be a reactivation.

---

| 102         | 1006     | 2022-07-05 | 107                |
