# SQL Scenario-Based Interview Question: E-commerce Customer Resurrection Analysis

## Business Scenario
An E-commerce company is analyzing customer behavior to identify "resurrected" customers. These are valuable customers who had stopped making purchases for a significant period but have since returned. As a Data Analyst, your task is to identify specific orders that signify a customer's resurrection. This understanding will help the marketing team design re-engagement campaigns or analyze the effectiveness of past initiatives.

Assume:
```sql
CURRENT_DATE = '2024-01-01'
```

---

# Database Setup

## Create orders Table
```sql
CREATE TABLE orders (
    order_id INT PRIMARY KEY,
    customer_id INT NOT NULL,
    order_date DATE NOT NULL,
    total_amount DECIMAL(10, 2) NOT NULL
);
```

# Task
Write a SQL query that identifies all orders that qualify as a "resurrection purchase." A resurrection purchase is defined as a purchase made by a customer where the `order_date` of this purchase is at least 60 days *after* the `order_date` of their immediately preceding purchase. A customer's very first purchase cannot be a resurrection purchase.

For each resurrection purchase, return the `customer_id`, `order_id`, and the number of `days_since_last_purchase` (the difference in days between the current order's `order_date` and the previous order's `order_date`).
