# SQL Scenario-Based Interview Question: Inventory Overstock/Understock Analysis

## Business Scenario
A large e-commerce company operates multiple warehouses. The operations team aims to optimize inventory levels to prevent both costly overstocking (tying up capital, increasing storage expenses) and critical understocking (leading to lost sales and customer dissatisfaction). They need a data-driven report to identify products that are potentially overstocked or understocked at each warehouse based on recent sales trends. As a Data Analyst, your task is to generate this crucial report.

Assume:
```sql
CURRENT_DATE = '2023-10-26'
```

## Create `inventory_movements` Table
```sql
CREATE TABLE inventory_movements (
    movement_id INT PRIMARY KEY,
    product_id INT,
    warehouse_id INT,
    movement_type VARCHAR(20), -- 'RECEIPT', 'SALE', 'ADJUSTMENT_IN', 'ADJUSTMENT_OUT'
    quantity INT,
    movement_date DATE,
    FOREIGN KEY (product_id) REFERENCES products(product_id),
    FOREIGN KEY (warehouse_id) REFERENCES warehouses(warehouse_id)
);
```

# Task
Write a SQL query to identify potential overstocked or understocked products at each warehouse. The report should include:
1.  **Product Name**
2.  **Warehouse Name**
3.  **Current Stock Level**: The net quantity of a product currently available at a specific warehouse as of `CURRENT_DATE`. 'RECEIPT' and 'ADJUSTMENT_IN' movements increase stock, while 'SALE' and 'ADJUSTMENT_OUT' movements decrease stock.
4.  **Average Daily Sales (ADS) - Last 30 Days**: The average daily quantity sold for that product at that warehouse over the 30 days *prior to* `CURRENT_DATE` (i.e., from `CURRENT_DATE - 30 days` to `CURRENT_DATE - 1 day`, inclusive of both ends). If no sales occurred in this period, ADS should be 0.
5.  **Days of Supply (DOS)**: `Current Stock Level / ADS`. This column should display a numeric value (rounded to 2 decimal places) when calculable. However, apply the following special logic:
    *   If ADS is 0 and Current Stock Level is > 0, DOS should be `'Overstock'`.
    *   If ADS is 0 and Current Stock Level is 0, DOS should be `'N/A'`.
    *   If Current Stock Level is 0 and ADS > 0, DOS should be `'Understock'`.
6.  **Stock Status**: Categorize based on DOS:
    *   `'Overstock'` if the calculated DOS (numeric) is > 90 days, or if DOS is `'Overstock'` (string).
    *   `'Understock'` if the calculated DOS (numeric) is < 7 days and DOS is not `'Understock'` (string).
    *   `'N/A'` if DOS is `'N/A'` (string).
    *   `'Healthy'` otherwise.

Consider only products that exist in the `products` table and warehouses in the `warehouses` table. Ensure that `quantity` values from `inventory_movements` are properly accounted for (e.g., a 'SALE' movement with 0 `quantity` should not affect ADS calculations as if it was a real sale).
