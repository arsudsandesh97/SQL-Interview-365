# SQL Scenario-Based Interview Question: Identifying At-Risk SaaS Customers Based on Feature Usage Drop

## Business Scenario
A SaaS company, "CloudFlow Analytics," provides a data visualization platform. As a Data Analyst, your team is tasked with proactively identifying customers who are showing signs of disengagement but haven't yet canceled their subscriptions. This information is crucial for the Customer Success team to intervene and prevent churn.

The business defines an "at-risk" customer as one who meets the following criteria:
1.  Their subscription is currently 'active'.
2.  They had *at least one usage event of a 'key_feature'* in the *previous calendar month* relative to `CURRENT_DATE`.
3.  They have had *zero usage events of any 'key_feature'* in the *current calendar month* (up to `CURRENT_DATE`).

You need to provide a list of `customer_id` and their `subscription_id` for all customers identified as "at-risk".

Assume:
```sql
CURRENT_DATE = '2024-03-15'
```

---

# Database Setup

## Create subscriptions Table
```sql
CREATE TABLE subscriptions (
    subscription_id INT PRIMARY KEY,
    customer_id INT,
    start_date DATE,
    status VARCHAR(50)
);
```

## Insert subscriptions Data
```sql
INSERT INTO subscriptions (subscription_id, customer_id, start_date, status) VALUES
(101, 1, '2023-01-01', 'active'),
(102, 2, '2023-02-10', 'active'),
(103, 3, '2023-03-01', 'cancelled'),
(104, 4, '2023-01-15', 'active'),
(105, 5, '2024-01-05', 'active'),
(106, 6, '2023-11-01', 'active');
```

## Create feature_usage Table
```sql
CREATE TABLE feature_usage (
    usage_id INT PRIMARY KEY,
    subscription_id INT,
    usage_timestamp DATETIME,
    feature_type VARCHAR(50)
);
```
