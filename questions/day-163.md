# SQL Scenario-Based Interview Question: Supply Chain Bottleneck Analysis

## Business Scenario
You are a Data Analyst for a large e-commerce company in their Logistics and Operations department. The team is experiencing intermittent delays in their order fulfillment and delivery process, leading to customer complaints and increased operational costs. Your manager needs your help to identify which specific stages in the supply chain process are contributing most significantly to these delays. The goal is to pinpoint stages where the average time taken exceeds the internal targets, so that operational improvements can be focused effectively.

Assume:
```sql
CURRENT_DATE = '2023-11-01'
```

---

# Database Setup

## Create `shipments` Table
```sql
CREATE TABLE shipments (
    shipment_id VARCHAR(50) PRIMARY KEY,
    customer_id VARCHAR(50) NOT NULL,
    order_date TIMESTAMP NOT NULL
);
```

## Insert `shipments` Data
```sql
INSERT INTO shipments (shipment_id, customer_id, order_date) VALUES
('S001', 'C101', '2023-10-26 09:00:00'),
('S002', 'C102', '2023-10-27 14:30:00'),
('S003', 'C103', '2023-10-28 10:00:00');
```

## Create `shipment_events` Table
```sql
CREATE TABLE shipment_events (
    event_id INT PRIMARY KEY AUTO_INCREMENT,
    shipment_id VARCHAR(50) NOT NULL,
    event_timestamp TIMESTAMP NOT NULL,
    event_stage VARCHAR(100) NOT NULL,
    FOREIGN KEY (shipment_id) REFERENCES shipments(shipment_id)
);
```

## Insert `shipment_events` Data
```sql

('S001', '2023-10-27 08:00:00', 'Warehouse Pick'),
('S001', '2023-10-29 07:00:00', 'In Transit'),

```

## Create `process_stages` Table
```sql
CREATE TABLE process_stages (
    stage_order INT PRIMARY KEY,
    stage_name VARCHAR(100) UNIQUE NOT NULL,
    expected_duration_hours INT -- Expected time in hours from the start of this stage to the start of the next stage
);
```

## Insert `process_stages` Data

# Task
Identify all supply chain stages where the **average actual duration** (the time elapsed between the start of that stage and the start of the *next* stage for each shipment) **exceeds** its `expected_duration_hours`.

The output should list the `stage_name`, the `avg_actual_duration_hours` for that stage, and its `expected_duration_hours`. Only include stages that have completed at least one transition.

---

# Expected Output Format
| stage_name       | avg_actual_duration_hours | expected_duration_hours |
| :--------------- | :------------------------ | :---------------------- |
| Warehouse Pick   | 66.50                     | 48                      |
| Out for Delivery | 15.00                     | 12                      |
