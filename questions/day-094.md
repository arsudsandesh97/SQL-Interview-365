# SQL Scenario-Based Interview Question: Logistics Performance Analysis: Identifying Problematic Carrier-Route Combinations

## Business Scenario
An e-commerce logistics manager is struggling with customer complaints about delayed shipments. They need to identify which specific carrier-route combinations are consistently performing poorly, especially concerning high-priority orders. As a Data Analyst, you've been tasked with creating a "Problematic Carrier-Route Index" to highlight the worst offenders, enabling the manager to initiate targeted discussions with carriers and optimize delivery routes.

Assume:
```sql
CURRENT_DATE = '2024-07-20'
```

# Database Setup

## Create Carriers Table
```sql
CREATE TABLE Carriers (
    carrier_id VARCHAR(50) PRIMARY KEY,
    carrier_name VARCHAR(100) NOT NULL
);
```

## Create Routes Table
```sql
CREATE TABLE Routes (
    route_id VARCHAR(50) PRIMARY KEY,
    route_name VARCHAR(100) NOT NULL,
    origin_warehouse_id VARCHAR(50),
    destination_warehouse_id VARCHAR(50)
);
```

## Create Shipments Table
```sql
CREATE TABLE Shipments (
    shipment_id VARCHAR(50) PRIMARY KEY,
    order_id VARCHAR(50) NOT NULL,
    carrier_id VARCHAR(50) NOT NULL,
    route_id VARCHAR(50) NOT NULL,
    priority_level VARCHAR(10) NOT NULL CHECK (priority_level IN ('High', 'Medium', 'Low')),

    actual_delivery_date DATE, -- NULL if not yet delivered or lost
    FOREIGN KEY (carrier_id) REFERENCES Carriers(carrier_id),
    FOREIGN KEY (route_id) REFERENCES Routes(route_id)
);
```

# Task
Calculate a "Problematic Carrier-Route Index" for each unique combination of `carrier_name` and `route_name`. This index should represent the average "Weighted Delay Score" for all shipments handled by that carrier-route combination.

The `Weighted Delay Score` for a single shipment is calculated as:
`(DATEDIFF(day, scheduled_delivery_date, actual_delivery_date)) * priority_weight`

The `priority_weight` should be assigned based on `priority_level`:
*   'High': 3
*   'Medium': 2
*   'Low': 1

Only consider shipments that meet the following criteria:
1.  `actual_delivery_date` is not NULL.
2.  The shipment was actually delayed (`actual_delivery_date > scheduled_delivery_date`).

Finally, rank these carrier-route combinations by their "Problematic Carrier-Route Index" in descending order and return the top 5. If there are fewer than 5, return all available.
