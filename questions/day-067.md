# SQL Scenario-Based Interview Question: Proactive Churn Risk Detection for SaaS Subscriptions

## Business Scenario
'CloudSync Pro' is a SaaS company offering cloud storage and synchronization services with various subscription tiers. The Customer Success team aims to proactively identify "at-risk" customers who, despite having renewed their subscriptions, have significantly reduced their application usage in the current cycle compared to their previous complete cycle. This early detection helps prioritize outreach to prevent future churn. As a Data Analyst, you need to identify these customers, excluding those already nearing their renewal date (within 30 days), to allow the dedicated renewal team to focus on them.

Assume:
```sql
CURRENT_DATE = '2023-11-15'
```

---

# Database Setup

## Create customers Table
```sql
CREATE TABLE customers (
    customer_id INT PRIMARY KEY,
    customer_name VARCHAR(100) NOT NULL
);
```

## Create subscriptions Table
```sql
CREATE TABLE subscriptions (
    subscription_id INT PRIMARY KEY,
    customer_id INT NOT NULL,
    start_date DATE NOT NULL,
    end_date DATE NOT NULL,
    status VARCHAR(50) NOT NULL, -- e.g., 'active', 'renewed', 'cancelled'
    tier VARCHAR(50) NOT NULL,   -- e.g., 'Basic', 'Pro', 'Enterprise'
    FOREIGN KEY (customer_id) REFERENCES customers(customer_id)
);
```

# Task
Identify customers who are "at-risk" based on the following criteria:
1.  They currently have an `active` subscription.
2.  Their current active subscription is NOT expiring within the next 30 days from `CURRENT_DATE`.
3.  They have completed at least one previous subscription cycle.
4.  Their average daily usage in the *current* active subscription cycle (from `start_date` of current cycle up to `CURRENT_DATE`) has decreased by more than 25% compared to their average daily usage in the *immediately preceding complete* subscription cycle.

Calculate:
-   `avg_daily_usage_current`: Total usage hours in the current cycle up to `CURRENT_DATE` divided by the number of days elapsed in the current cycle.
-   `avg_daily_usage_previous`: Total usage hours in the previous complete cycle divided by the total duration of the previous complete cycle.
-   `percentage_drop`: The percentage decrease in average daily usage from the previous cycle to the current cycle, rounded to 2 decimal places.
-   `days_to_renewal`: Number of days remaining until the `end_date` of the current subscription, from `CURRENT_DATE`.

Order the results by `customer_id`.
