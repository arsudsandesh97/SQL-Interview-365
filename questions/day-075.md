# SQL Scenario-Based Interview Question: Pro-rated Monthly Subscription Revenue Calculation

## Business Scenario
An E-commerce SaaS company offers various subscription plans (e.g., Basic, Premium, VIP) to its customers. Customers can upgrade, downgrade, or cancel their plans at any point during their billing cycle. The finance department needs to accurately calculate the *pro-rated revenue* earned from subscriptions for a specific month. This calculation must account for customers who changed plans mid-month, ensuring that revenue is recognized only for the days a customer was active on a particular plan within that month. As a Data Analyst, you need to provide a query that calculates the total pro-rated revenue for each customer for a given target month.

Assume:
```sql
CURRENT_DATE = '2023-03-15' -- This date is irrelevant; the target month is fixed as '2023-01'.
```

---

# Database Setup

## Create Customers Table
```sql
CREATE TABLE Customers (
    customer_id INT PRIMARY KEY,
    customer_name VARCHAR(100) NOT NULL
);
```

## Insert Customers Data
```sql
INSERT INTO Customers (customer_id, customer_name) VALUES
(101, 'Alice Johnson'),
(102, 'Bob Williams'),
(103, 'Carol Davis'),
(104, 'David Lee');
```

## Create Plans Table
```sql
CREATE TABLE Plans (
    plan_id INT PRIMARY KEY,
    plan_name VARCHAR(50) NOT NULL,
    monthly_price DECIMAL(10, 2) NOT NULL
);
```

## Insert Plans Data
```sql
INSERT INTO Plans (plan_id, plan_name, monthly_price) VALUES
(1, 'Basic', 10.00),
(2, 'Premium', 25.00),
(3, 'VIP', 50.00);
```

## Create Subscriptions Table
```sql
CREATE TABLE Subscriptions (
    subscription_id INT PRIMARY KEY,
    customer_id INT NOT NULL,
    plan_id INT NOT NULL,
    start_date DATE NOT NULL,
    end_date DATE, -- NULL means the subscription is currently active
    FOREIGN KEY (customer_id) REFERENCES Customers(customer_id),
    FOREIGN KEY (plan_id) REFERENCES Plans(plan_id)
);
```

## Insert Subscriptions Data
```sql
INSERT INTO Subscriptions (subscription_id, customer_id, plan_id, start_date, end_date) VALUES
(1, 101, 1, '2022-12-01', '2023-01-15'), -- Alice on Basic
(2, 101, 2, '2023-01-16', NULL),         -- Alice upgraded to Premium
(3, 102, 3, '2023-01-01', '2023-01-10'), -- Bob on VIP, then cancelled
(4, 103, 1, '2023-01-05', NULL),         -- Carol on Basic
(5, 104, 2, '2022-11-01', '2022-12-31'), -- David on Premium, cancelled before target month
(6, 104, 3, '2023-02-01', NULL);         -- David on VIP, started after target month
```

# Task
Write a SQL query that calculates the total pro-rated subscription revenue for each customer for the **month of January 2023**.
The pro-rated revenue for a specific plan segment within the month should be calculated as:
`(plan_monthly_price / total_days_in_target_month) * number_of_days_active_on_plan_in_target_month`

The query should return `customer_id`, `customer_name`, and `total_prorated_revenue` for the target month, rounded to 2 decimal places. Customers with no active subscriptions in January 2023 should not be included in the output.
