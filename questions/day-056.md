# SQL Scenario-Based Interview Question: Uncovering Suspicious Transaction Patterns

## Business Scenario
You are a Data Analyst at a major financial institution's Fraud Detection Unit. The bank is experiencing an increase in sophisticated fraud attempts and needs proactive methods to identify suspicious transaction patterns. Your team has identified two specific patterns that often indicate fraudulent activity, and you're tasked with writing a SQL query to flag such transactions for immediate investigation.

Assume:
```sql
CURRENT_DATE = '2023-10-26'
```

    transaction_datetime DATETIME NOT NULL,

    transaction_location VARCHAR(100) NOT NULL

# Task
Your task is to write a SQL query that identifies potentially fraudulent transactions based on the following two criteria:

1.  **Rapid Multi-Location Transactions:** Flag a transaction if the `account_id` has had a *previous* transaction within a 10-minute window, and the `transaction_location` of the current transaction is *different* from the previous one.
2.  **High-Value Transaction After Inactivity:** Flag a transaction if its `transaction_amount` is greater than `$5000` AND the time difference between the current transaction and the *previous* transaction for the same `account_id` is more than 30 days.

Your query should return the `account_id`, `transaction_id`, and a `flag_reason` column indicating which rule(s) were triggered (e.g., 'Rapid Multi-Location', 'High-Value After Inactivity', or 'Both'). If a transaction matches both criteria, list 'Both'.
