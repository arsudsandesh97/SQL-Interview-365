# SQL Scenario-Based Interview Question: SaaS User Engagement: Longest Consecutive Active Month Streak

## Business Scenario
You are a Data Analyst at "GrowthMind Analytics," a SaaS company providing productivity tools. The product team is keen to understand user engagement and "stickiness" more deeply. They believe that users who maintain long streaks of consecutive active months are more valuable and less likely to churn.

Your task is to analyze the `user_events` data to determine the longest continuous streak of active months for each user. An "active month" is defined as any calendar month where a user has at least one recorded event.

Assume:
```sql
CURRENT_DATE = '2023-10-26'
```

---

# Database Setup

## Create user_events Table
```sql
CREATE TABLE user_events (
    event_id INT PRIMARY KEY,
    user_id INT NOT NULL,
    event_timestamp TIMESTAMP NOT NULL,
    event_type VARCHAR(50) NOT NULL
);
```

# Task
Write a SQL query that returns the `user_id` and their `longest_active_streak` (number of consecutive active months).
Order the results by `user_id` in ascending order.
Users who have been active for only a single month should have a streak of 1.

---

# Expected Output Format
| user_id | longest_active_streak |
| :------ | :-------------------- |
| 101     | 3                     |
| 102     | 2                     |
| 103     | 7                     |

| 105     | 3                     |
