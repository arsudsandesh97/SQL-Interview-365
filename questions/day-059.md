# SQL Scenario-Based Interview Question: SaaS Customer Subscription Lifecycle Analysis

## Business Scenario
You are a Data Analyst at a growing SaaS company. The product management team is keen to understand customer subscription dynamics. Specifically, they want to analyze monthly changes in customer subscription plans to track upgrades, downgrades, new sign-ups, and churn. This insight will help them evaluate product strategy, marketing campaigns, and customer retention efforts. Your task is to generate a report that, for each customer and each month, identifies the nature of their subscription change compared to the immediately preceding month.

Assume:
```sql
CURRENT_DATE = '2023-04-15'
```

---

# Database Setup

## Create `plan_details` Table
```sql
CREATE TABLE plan_details (
    plan_name VARCHAR(50) PRIMARY KEY,
    plan_level INT NOT NULL,
    monthly_price DECIMAL(10, 2) NOT NULL
);
```

## Insert `plan_details` Data
```sql
INSERT INTO plan_details (plan_name, plan_level, monthly_price) VALUES
('Free', 0, 0.00),
('Basic', 1, 10.00),
('Pro', 2, 25.00),
('Enterprise', 3, 50.00);
```

## Create `customer_monthly_subscriptions` Table
```sql
CREATE TABLE customer_monthly_subscriptions (
    snapshot_month DATE NOT NULL, -- Represents the start of the month (e.g., '2023-01-01' for January)
    customer_id INT NOT NULL,
    plan_name VARCHAR(50) NOT NULL,
    PRIMARY KEY (snapshot_month, customer_id),
    FOREIGN KEY (plan_name) REFERENCES plan_details(plan_name)
);
```

## Insert `customer_monthly_subscriptions` Data
```sql
INSERT INTO customer_monthly_subscriptions (snapshot_month, customer_id, plan_name) VALUES
('2023-01-01', 101, 'Basic'),
('2023-01-01', 102, 'Pro'),
('2023-01-01', 103, 'Free'), -- Customer 103 started on a free plan
('2023-02-01', 101, 'Pro'), -- 101 Upgrade
('2023-02-01', 102, 'Basic'), -- 102 Downgrade
('2023-02-01', 104, 'Basic'), -- 104 New
('2023-03-01', 101, 'Pro'), -- 101 No Change
('2023-03-01', 102, 'Free'), -- 102 Downgrade again
('2023-03-01', 103, 'Pro'), -- 103 Re-subscribed after churn, now on Pro
('2023-03-01', 105, 'Enterprise'), -- 105 New
('2023-04-01', 102, 'Basic'), -- 102 Upgrade
('2023-04-01', 103, 'Enterprise'), -- 103 Upgrade
('2023-04-01', 104, 'Pro'); -- 104 Re-subscribed after churn, now on Pro
```

# Task
Generate a report that identifies the subscription status and change type for each customer in each month, compared to the *immediately preceding month*. The report should include the `snapshot_month`, `customer_id`, the `current_plan`, and a `change_type` column.

The `change_type` should be categorized as follows:
*   **'New Subscription'**: Customer was not subscribed in the previous month but is subscribed in the current month. This also applies to re-subscribing customers.
*   **'Upgrade'**: Customer was subscribed in the previous month and is now on a plan with a *higher `plan_level`*.
*   **'Downgrade'**: Customer was subscribed in the previous month and is now on a plan with a *lower `plan_level`*.
*   **'No Change'**: Customer was subscribed in the previous month and is on the *same `plan_name`* in the current month.
*   **'Churned'**: Customer was subscribed in the previous month but is *not subscribed* in the current month. (For 'Churned' customers, the `current_plan` should be 'N/A').

The report should cover all months present in `customer_monthly_subscriptions` and implicitly account for churned customers by including them in the month *after* they were last seen (i.e., if a customer was active in March but not April, they should show as 'Churned' in April). The first month of data for any customer should always show 'New Subscription'.
