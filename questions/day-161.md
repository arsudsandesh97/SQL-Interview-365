# SQL Scenario-Based Interview Question: Proactive Churn Identification for SaaS Subscriptions

## Business Scenario
You are a Data Analyst at "CloudFlow Solutions," a SaaS company providing subscription-based services. The marketing and retention teams want to proactively identify high-value customers with active subscriptions who are due for renewal in the next 30 days but show a significant decline in their recent spending activity. The goal is to flag these "at-risk" customers for targeted retention campaigns before their subscription renews.

Assume:
```sql
CURRENT_DATE = '2023-10-26'
```

# Database Setup

## Create Customers Table
```sql
CREATE TABLE Customers (
    customer_id INT PRIMARY KEY,
    customer_name VARCHAR(255)
);
```

## Create Subscriptions Table
```sql
CREATE TABLE Subscriptions (
    subscription_id INT PRIMARY KEY,
    customer_id INT,
    plan_name VARCHAR(100),
    start_date DATE,
    end_date DATE, -- This is the next renewal date for active subscriptions
    status VARCHAR(50),
    FOREIGN KEY (customer_id) REFERENCES Customers(customer_id)
);
```

# Task
Identify 'at-risk' customers by finding active subscriptions that meet ALL of the following criteria:

1.  **Renewal Window:** The subscription's `end_date` (next renewal date) is within the next 30 days from `CURRENT_DATE`.
2.  **Active Status:** The subscription `status` is 'Active'.
3.  **Recent Spending Decline:** The total `order_value` from orders placed in the last 90 days (from `CURRENT_DATE`) for that subscription is less than 75% of its historical average monthly spend, extrapolated for a 90-day period.

    *   `Total_Order_Value_Last_90_Days`: Sum of `order_value` for all orders associated with the specific `subscription_id` where `order_date` is between `DATE_SUB(CURRENT_DATE, INTERVAL 90 DAY)` and `CURRENT_DATE`. If no orders in this period, consider it 0.
    *   `Historical_Average_Monthly_Spend`: (Total `order_value` for all orders associated with the specific `subscription_id` from `start_date` up to `CURRENT_DATE`) / (Number of months the subscription has been active until `CURRENT_DATE`).
        *   The "Number of months active" should be calculated as `GREATEST(1, CEIL(DATEDIFF(CURRENT_DATE, S.start_date) / 30.0))`. This ensures the denominator is at least 1 to avoid division by zero.
    *   **Condition:** `Total_Order_Value_Last_90_Days < 0.75 * (Historical_Average_Monthly_Spend * 3)`

Your query should return `customer_id`, `customer_name`, `subscription_id`, `plan_name`, `renewal_date`, `Total_Order_Value_Last_90_Days`, and `Projected_Historical_90_Day_Spend`.
