# SQL Scenario-Based Interview Question: Identifying E-commerce Customer Reactivation Events

## Business Scenario
You are a Data Analyst at a growing e-commerce company specializing in subscription boxes and one-time purchases. The Marketing team is keen to understand customer reactivation patterns. They want to identify customers who have shown a significant period of inactivity (dormancy) and then made a new purchase, as these customers represent successful re-engagement opportunities. Your task is to extract a list of all such "reactivation events" to help the team analyze their re-engagement strategies and customer lifecycle.

Assume:
```sql
CURRENT_DATE = '2023-10-26'
```

---

# Database Setup

## Create Customers Table
```sql
CREATE TABLE Customers (
    customer_id INT PRIMARY KEY,
    customer_name VARCHAR(100)
);
```

## Insert Customers Data
```sql
INSERT INTO Customers (customer_id, customer_name) VALUES
(101, 'Alice Smith'),
(102, 'Bob Johnson'),
(103, 'Charlie Brown'),
(104, 'David Lee');
```

## Create Orders Table
```sql
CREATE TABLE Orders (
    order_id INT PRIMARY KEY,
    customer_id INT,
    order_date DATE,
    total_amount DECIMAL(10, 2),
    FOREIGN KEY (customer_id) REFERENCES Customers(customer_id)
);
```

## Insert Orders Data

# Task
Write a SQL query that identifies all customer reactivation events. A customer reactivation event is defined as a purchase made by a customer after a period of at least 90 days since their last recorded purchase.

For each such reactivation event, return the `customer_id`, `customer_name`, and the `reactivation_date` (which is the `order_date` of the purchase that marks the end of the dormancy period).
Order the results by `customer_id` and then by `reactivation_date`.

---

# Expected Output Format
| customer_id | customer_name | reactivation_date |
|-------------|---------------|-------------------|
| 101         | Alice Smith   | 2022-06-01        |
| 101         | Alice Smith   | 2022-11-15        |
| 102         | Bob Johnson   | 2023-01-01        |
