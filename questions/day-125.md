# SQL Scenario-Based Interview Question: Monthly Subscription Downgrade Analysis

## Business Scenario
An e-commerce company operates a premium membership program with multiple tiers (e.g., Bronze, Silver, Gold, Platinum). The Marketing and Product teams are concerned about customer retention and want to analyze subscription downgrades. They need to identify customers who downgraded their subscription tier during the *last full calendar month* (relative to `CURRENT_DATE`). A downgrade is defined as a customer moving from a tier with a higher `tier_level` to a tier with a lower `tier_level`. This analysis helps them understand churn patterns and target interventions.

Assume:
```sql
CURRENT_DATE = '2024-03-15'
```

---

# Database Setup

## Create subscription_tiers Table
```sql
CREATE TABLE subscription_tiers (
    tier_id INT PRIMARY KEY,
    tier_name VARCHAR(50) NOT NULL,
    monthly_price DECIMAL(10, 2) NOT NULL,
    tier_level INT NOT NULL -- Higher number indicates a higher tier (e.g., Bronze=1, Silver=2, Gold=3, Platinum=4)
);
```

## Insert subscription_tiers Data
```sql
INSERT INTO subscription_tiers (tier_id, tier_name, monthly_price, tier_level) VALUES
(101, 'Bronze', 9.99, 1),
(102, 'Silver', 19.99, 2),
(103, 'Gold', 29.99, 3),
(104, 'Platinum', 49.99, 4);
```

## Create customer_subscription_history Table
```sql
CREATE TABLE customer_subscription_history (
    record_id INT PRIMARY KEY AUTO_INCREMENT,
    customer_id INT NOT NULL,
    tier_id INT NOT NULL,
    change_date DATE NOT NULL,
    FOREIGN KEY (tier_id) REFERENCES subscription_tiers(tier_id)
);
```

# Task
Identify unique customers who downgraded their subscription tier during the *last full calendar month* relative to `CURRENT_DATE ('2024-03-15')`. The last full calendar month is February 2024 (from `2024-02-01` to `2024-02-29`).

For each identified downgrade:
1.  Display the `downgrade_month` in 'Mon YYYY' format (e.g., 'Feb 2024').
2.  Display the `customer_id`.
3.  Display the `tier_name` of the tier they were on *immediately before* the downgrade.
4.  Display the `tier_name` of the tier they *downgraded to*.

A downgrade occurs when a customer's `change_date` falls within the last full month, and their new `tier_level` is strictly lower than their `tier_level` from the immediately preceding subscription change (ordered by `change_date`).
