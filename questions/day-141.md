# SQL Scenario-Based Interview Question: Identifying At-Risk Subscribers for Onboarding Intervention

## Business Scenario
You are a Data Analyst at 'BoxedDelights', a rapidly growing subscription box service for gourmet snacks. The customer success team wants to proactively identify subscribers who might be struggling with their onboarding or are at high risk of churning early. They've noticed that customers who either never place their first order or whose first order is significantly delayed after subscription sign-up tend to churn quickly. Your task is to provide a list of such customers for targeted intervention.

Assume:
```sql
CURRENT_DATE = '2023-10-26'
```

---

# Database Setup

## Create Customers Table
```sql
CREATE TABLE Customers (
    customer_id VARCHAR(50) PRIMARY KEY,
    subscription_start_date DATE,
    region VARCHAR(50)
);
```

## Insert Customers Data
```sql

```

## Create Orders Table
```sql
CREATE TABLE Orders (
    order_id VARCHAR(50) PRIMARY KEY,
    customer_id VARCHAR(50),
    order_date DATE,
    order_value DECIMAL(10, 2),
    FOREIGN KEY (customer_id) REFERENCES Customers(customer_id)
);
```

# Task
Write a SQL query to identify customers who are at risk. A customer is considered 'at risk' if:
1. They have subscribed more than 30 days ago (relative to `CURRENT_DATE = '2023-10-26'`) and have **never placed any order**.
2. They have placed an order, but their **first order date** was more than 30 days after their `subscription_start_date`.

The query should return `customer_id`, `subscription_start_date`, `first_order_date` (NULL if no orders), and a `risk_reason` (e.g., 'No First Order After 30 Days' or 'Delayed First Order').

---

| C102        | 2023-09-10              | 2023-10-15       | Delayed First Order        |
