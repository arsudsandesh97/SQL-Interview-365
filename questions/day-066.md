# SQL Scenario-Based Interview Question: Longest Post-Trial Active Usage Streak

## Business Scenario
A leading SaaS company offers various modular products (e.g., CRM, Project Management, Analytics) to its business customers. Customers can subscribe to one or more products. The company wants to deeply understand customer "stickiness" beyond just subscription payments. Specifically, they define "post-trial active usage" as a customer having at least one 'Paid' subscription active for a product during any part of that calendar month and recording at least one usage event for any of their *currently paid* products within that same month.

As a Data Analyst, your task is to identify for each customer their *longest consecutive period* (in months) of "post-trial active usage". This metric helps in identifying core, engaged users and understanding long-term retention patterns, distinguishing actual engagement from mere subscription status.

Assume:
```sql
CURRENT_DATE = '2023-11-15'
```

# Database Setup

## Create customers Table
```sql
CREATE TABLE customers (
    customer_id INT PRIMARY KEY,
    customer_name VARCHAR(100) NOT NULL
);
```

## Insert customers Data
```sql
INSERT INTO customers (customer_id, customer_name) VALUES
(1, 'Alice'),
(2, 'Bob'),
(3, 'Charlie');
```

## Create subscriptions Table
```sql
CREATE TABLE subscriptions (
    subscription_id INT PRIMARY KEY,
    customer_id INT NOT NULL,
    product_id VARCHAR(50) NOT NULL, -- e.g., 'CRM', 'Analytics'
    start_date DATE NOT NULL,
    end_date DATE, -- NULL if ongoing
    subscription_type VARCHAR(10) NOT NULL, -- 'Trial' or 'Paid'
    FOREIGN KEY (customer_id) REFERENCES customers(customer_id)
);
```

# Task
Calculate the maximum consecutive months of "post-trial active usage" for each customer. A customer is considered "post-trial active" in a given calendar month if:
1.  They have at least one 'Paid' subscription active for a product during any part of that month. A subscription is active if its `start_date` is on or before the end of the month, and its `end_date` is NULL or on or after the beginning of the month.
2.  They recorded at least one usage event for *any* of their products *under a 'Paid' subscription* within that same month. (i.e., the `usage_timestamp` falls within a period where the `product_id` was under a 'Paid' subscription for that customer).
Consider all months up to and including the month of `CURRENT_DATE`. If a customer has never been "post-trial active", their `max_consecutive_active_months` should be 0.
