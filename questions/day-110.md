# SQL Scenario-Based Interview Question: Re-engaging High-Value Customers in Specific Categories

## Business Scenario
You are a Data Analyst at "GadgetGrove," an E-commerce company specializing in electronics. The marketing team is planning a targeted re-engagement campaign for customers who have historically shown high spending patterns in the "Premium Electronics" category but have recently stopped purchasing from that specific category, while still remaining active with other purchases on the platform. The goal is to identify these customers to prevent potential churn from a high-margin product segment.

Your task is to identify customers who meet the following criteria:
1.  They have made at least one purchase from the "Premium Electronics" category, with a cumulative total spend in this category exceeding $500 across all their orders.
2.  Their *last purchase* from the "Premium Electronics" category was more than 90 days ago.
3.  They have made *any other purchase* (from any category) within the last 60 days, indicating they are still active on the platform.

Assume:
```sql
CURRENT_DATE = '2023-10-26'
```

# Database Setup

## Create Customers Table
```sql
CREATE TABLE Customers (
    customer_id INT PRIMARY KEY,
    customer_name VARCHAR(100),
    registration_date DATE
);
```

## Insert Customers Data
```sql

(102, 'Jane Smith', '2022-03-20'),
(103, 'Bob Johnson', '2021-11-01'),
(104, 'Alice Brown', '2023-05-10');
```

## Create Products Table
```sql
CREATE TABLE Products (
    product_id INT PRIMARY KEY,
    product_name VARCHAR(100),
    category VARCHAR(50),
    unit_price DECIMAL(10, 2)
);
```

## Create Orders Table
```sql
CREATE TABLE Orders (
    order_id INT PRIMARY KEY,
    customer_id INT,
    order_date DATE,
    total_amount DECIMAL(10, 2),
    FOREIGN KEY (customer_id) REFERENCES Customers(customer_id)
```

## Create Order_Items Table
```sql
CREATE TABLE Order_Items (
    order_item_id INT PRIMARY KEY,
    order_id INT,
    product_id INT,

    item_price DECIMAL(10, 2),
```

Order the results by `customer_id`.
