# SQL Scenario-Based Interview Question: Identifying At-Risk Subscription Customers

## Business Scenario
You are a Data Analyst at "BoxedDelights," an e-commerce company offering various subscription box services. The marketing team is concerned about customer churn and wants to proactively identify "at-risk" customers who are showing signs of disengagement. They believe that customers who perform multiple distinct disengagement actions within a recent period are more likely to cancel their subscriptions soon. Your task is to provide a list of these at-risk customers to enable targeted retention campaigns.

Assume:
```sql
CURRENT_DATE = '2023-10-26'
```

---

# Database Setup

## Create Customers Table
```sql
CREATE TABLE Customers (
    customer_id INT PRIMARY KEY,
    customer_name VARCHAR(100),
    email VARCHAR(100)
);
```

## Insert Customers Data
```sql
INSERT INTO Customers (customer_id, customer_name, email) VALUES
(101, 'Alice Johnson', 'alice@example.com'),
(102, 'Bob Williams', 'bob@example.com'),
(103, 'Carol Davis', 'carol@example.com'),
(104, 'David Brown', 'david@example.com'),
(105, 'Eve White', 'eve@example.com');
```

## Create Subscriptions Table
```sql
CREATE TABLE Subscriptions (
    subscription_id VARCHAR(50) PRIMARY KEY,
    customer_id INT,
    start_date DATE,
    end_date DATE, -- NULL if active
    status VARCHAR(50), -- e.g., 'active', 'paused', 'cancelled'
    FOREIGN KEY (customer_id) REFERENCES Customers(customer_id)
);
```

## Insert Subscriptions Data
```sql
INSERT INTO Subscriptions (subscription_id, customer_id, start_date, end_date, status) VALUES
('S1', 101, '2022-01-01', NULL, 'active'),
('S2', 101, '2023-05-15', '2023-09-01', 'cancelled'),
('S3', 102, '2022-03-10', NULL, 'active'),
('S4', 103, '2023-07-20', NULL, 'active'),
('S5', 104, '2022-06-01', NULL, 'active'),
('S6', 105, '2023-01-01', NULL, 'active');
```

## Create SubscriptionEvents Table
```sql
CREATE TABLE SubscriptionEvents (
    event_id INT PRIMARY KEY AUTO_INCREMENT,
    subscription_id VARCHAR(50),
    event_type VARCHAR(100), -- e.g., 'skipped_box', 'paused_subscription', 'resumed_subscription', 'cancelled_subscription'
    event_date DATE,
    FOREIGN KEY (subscription_id) REFERENCES Subscriptions(subscription_id)
);
```

## Insert SubscriptionEvents Data
```sql
INSERT INTO SubscriptionEvents (subscription_id, event_type, event_date) VALUES

('S1', 'skipped_box', '2023-02-10'),        -- Alice: OUTSIDE 90 days
('S6', 'skipped_box', '2023-09-20');        -- Eve: within 90 days, disengagement
```

# Task
Identify `customer_id` and `customer_name` for customers who have performed at least two *distinct types* of "disengagement" actions across any of their subscriptions within the last 90 days from `CURRENT_DATE`. The "disengagement" event types are defined as `'skipped_box'` and `'paused_subscription'`. Also, include a column showing the count of these distinct disengagement action types for each identified customer.

---

# Expected Output Format
| customer_id | customer_name | distinct_disengagement_types |
|-------------|---------------|------------------------------|
| 101         | Alice Johnson | 2                            |
| 105         | Eve White     | 2                            |
