# SQL Scenario-Based Interview Question: Analyzing Flash Sale Impact on Repeat Purchase Lag

## Business Scenario
An E-commerce company, 'TrendCart', recently ran a 3-day flash sale to attract new customers and boost sales. The marketing team wants to evaluate the long-term effectiveness of this campaign. They specifically want to identify customers whose *first-ever purchase* occurred *during the flash sale period*. For these identified customers, they need to calculate the *average number of days* between their first purchase (during the sale) and their *first subsequent purchase* that occurred strictly *after the flash sale ended*. This metric will help them understand if the flash sale attracted valuable customers likely to return or merely one-time opportunistic buyers.

Assume:
```sql
CURRENT_DATE = '2023-11-30'
```

---

# Database Setup

## Create Customers Table
```sql
CREATE TABLE Customers (
    customer_id INT PRIMARY KEY,
    registration_date DATE
);
```

## Insert Customers Data
```sql
INSERT INTO Customers (customer_id, registration_date) VALUES
(1, '2023-09-01'),
(2, '2023-10-01'),
(3, '2023-10-15'),
(4, '2023-09-10'),
```

## Create Orders Table
```sql
CREATE TABLE Orders (
    order_id INT PRIMARY KEY,
    customer_id INT,
    order_date DATE,
    total_amount DECIMAL(10, 2),
    FOREIGN KEY (customer_id) REFERENCES Customers(customer_id)
);
```

# Task
Identify all customers whose *first-ever purchase* date falls within the flash sale period ('2023-10-15' to '2023-10-17' inclusive). For *only these customers*, find their *first subsequent purchase date* that occurred strictly *after the flash sale ended* ('2023-10-17'). Finally, calculate the *average number of days* between their first purchase (during the sale) and this first subsequent purchase (after the sale). If a customer made a first purchase during the sale but no subsequent purchase strictly after the sale, they should not be included in the average calculation.

The flash sale period is from '2023-10-15' to '2023-10-17'.
The end of the flash sale is '2023-10-17'.

---
