# SQL Scenario-Based Interview Question: Identifying Repurchase-After-Return Patterns

## Business Scenario
An e-commerce company is concerned about customer behavior where products are returned only to be repurchased by the same customer shortly after. This pattern can lead to increased operational costs (shipping, handling returns) and might indicate issues like customers trying out products without commitment, taking advantage of price drops, or "wardrobing". The Marketing and Operations teams want to identify customers who exhibit this "return-then-repurchase" behavior for the *exact same product* within a 60-day window after the return. They need to quantify how often this happens and understand the typical time lag between the return and repurchase.

Assume:
```sql
CURRENT_DATE = '2023-10-26'
```

# Database Setup

## Create Customers Table
```sql
CREATE TABLE Customers (
    customer_id INT PRIMARY KEY,
    customer_name VARCHAR(100),
    registration_date DATE
);
```

## Insert Customers Data
```sql

(1, 'Alice', '2022-01-01'),
(2, 'Bob', '2022-03-15'),
(3, 'Charlie', '2023-01-01');
```

## Create Products Table
```sql
CREATE TABLE Products (
    product_id INT PRIMARY KEY,
    product_name VARCHAR(100),
    sku VARCHAR(50),
    category VARCHAR(50)
);
```


## Create Orders Table
```sql
CREATE TABLE Orders (
    order_id INT PRIMARY KEY,
    customer_id INT,
    order_date DATE,
    total_amount DECIMAL(10, 2),
    FOREIGN KEY (customer_id) REFERENCES Customers(customer_id)

```

```sql
CREATE TABLE Order_Items (
    item_id INT PRIMARY KEY, -- Unique line item ID

    unit_price DECIMAL(10, 2),
    FOREIGN KEY (order_id) REFERENCES Orders(order_id),
    FOREIGN KEY (product_id) REFERENCES Products(product_id)
```

# Task
Identify customers who have returned a specific product (identified by `product_id`) and then subsequently repurchased the *exact same product* (same `product_id`) within 60 days of the return date.

For each such customer and product combination, calculate:
1.  The total number of times this "return-then-repurchase" cycle occurred.
2.  The average time difference (in days) between the return date and the subsequent repurchase date.

Only include cycles where the repurchase occurred strictly after the return, and within the 60-day window.

---

# Expected Output Format

| customer_name | product_sku | total_return_repurchase_cycles | avg_days_between_events |
| :------------ | :---------- | :----------------------------- | :---------------------- |
| Alice         | HEADX001    | 2                              | 36.5                    |
