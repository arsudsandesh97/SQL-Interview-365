# SQL Scenario-Based Interview Question: SaaS Customer Churn Risk Identification

## Business Scenario
A rapidly growing SaaS company, 'CloudFlow Solutions', is keen on proactively identifying customers who might be at risk of churning. They have observed that customers who have significantly reduced their subscription value after reaching a higher tier, especially if this downgrade happened recently, are more likely to cancel their service. As a Data Analyst, your task is to identify these 'at-risk' customers to enable the customer success team to intervene with targeted retention strategies.

Assume:
```sql
CURRENT_DATE = '2023-10-26'
```

---

# Database Setup

## Create Customers Table
```sql
CREATE TABLE Customers (
    customer_id INT PRIMARY KEY,
    customer_name VARCHAR(100),
    email VARCHAR(100),
    join_date DATE
);
```

## Create Plans Table
```sql
CREATE TABLE Plans (
    plan_id INT PRIMARY KEY,
    plan_name VARCHAR(50),
    monthly_cost DECIMAL(10, 2)
);
```


## Create Subscription_History Table
```sql
CREATE TABLE Subscription_History (
    subscription_id INT PRIMARY KEY,
    customer_id INT,
    plan_id INT,
    start_date DATE,
    end_date DATE, -- NULL for current active subscriptions
    status VARCHAR(20), -- e.g., 'Active', 'Cancelled', 'Expired', 'Trial'
    FOREIGN KEY (customer_id) REFERENCES Customers(customer_id),
    FOREIGN KEY (plan_id) REFERENCES Plans(plan_id)
);
```

# Task
Identify all 'at-risk' customers. A customer is considered 'at-risk' if ALL of the following conditions are met:
1.  They currently have an 'Active' subscription.
2.  Their current active subscription's `monthly_cost` is less than the `monthly_cost` of the *highest-tier plan* (based on `monthly_cost`) they have ever subscribed to.
3.  The most recent change to their *current active subscription* was a *downgrade* (i.e., changing from a higher `monthly_cost` plan to a lower `monthly_cost` plan) AND this downgrade occurred within the last 90 days relative to `CURRENT_DATE`.

Return the `customer_id`, `customer_name`, `email`, `current_plan_name`, `current_monthly_cost`, `highest_plan_name_ever`, `highest_monthly_cost_ever`, and `latest_downgrade_date`.
