# SQL Scenario-Based Interview Question: E-commerce Order Fulfillment and Delivery SLA Compliance

## Business Scenario
You are a Data Analyst at a growing E-commerce company. The Head of Operations is concerned about customer satisfaction related to delivery times and wants to proactively identify issues in the order fulfillment and delivery pipeline. They need a comprehensive report to evaluate the performance against two critical Service Level Agreements (SLAs):

1.  **Fulfillment SLA:** Orders must be shipped within 2 calendar days from the `order_date`.
2.  **Delivery SLA:** Orders must be delivered within 5 calendar days from the `shipped_date`.

Your task is to generate a report for all completed orders, clearly indicating whether each order met these SLAs, along with key details about its fulfillment.

Assume:
```sql
CURRENT_DATE = '2023-10-26'
```

## Create Orders Table
```sql
CREATE TABLE Orders (
    order_id INT PRIMARY KEY,
    customer_id INT,
    order_date DATE
```

```sql

    fulfillment_id INT PRIMARY KEY,
```

# Task
Generate a report for all completed orders that includes the following columns:
1.  `order_id`
2.  `fulfillment_center_id`
3.  `carrier_id`
4.  `fulfillment_duration_days`: The number of days between `order_date` and `shipped_date`.
5.  `delivery_duration_days`: The number of days between `shipped_date` and `delivered_date`.
6.  `is_fulfillment_late`: A boolean (TRUE/FALSE or 1/0) indicating if the `fulfillment_duration_days` exceeds the 'Fulfillment' SLA.
7.  `is_delivery_late`: A boolean (TRUE/FALSE or 1/0) indicating if the `delivery_duration_days` exceeds the 'Delivery' SLA.

Retrieve the `days_allowed` for SLAs from the `Service_Level_Agreements` table.
